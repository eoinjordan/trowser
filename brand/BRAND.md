# Trowser Brand System

## Brand idea

**Trowser** is the browser with the agent stuffed inside it. The joke is the hook; the architecture is the substance.

The product should feel local, mechanical, inspectable and slightly irreverent. It should not look like a generic purple-gradient AI assistant.

## Name

- Product: **Trowser**
- Category phrase: **browser-native agent runtime**
- Concept / meme: **Trowser Stuffing**
- Verb: **stuff** — “Stuff the agent into the browser.”

## Primary lines

1. **Stuff the agent into the browser.**
2. **Stop sending your browser to the agent.**
3. **The browser is the agent runtime.**
4. **DOM in. Local model. Browser actions out.**
5. **0 API keys. 0 cloud tokens.**

## Visual language

The mark combines a browser window and a heavy letter T. The short chevrons at the right edge represent repeated agent steps being packed into the browser frame.

Use large, compressed-looking headlines, small technical monospace annotations, visible rules, hard blocks and little ornamentation.

Avoid gradients, sparkles, robot heads, magic wands, brain icons and generic chat bubbles.

| Muted | `#77786F` | Secondary text |
| Danger | `#FF6847` | Consequential action warnings |

## Typography

Use system sans for the product by default so the extension ships without font assets.

- Headline: `Inter`, `Arial`, or system sans, weight 800–900.
- Technical labels: `ui-monospace`, `SFMono-Regular`, `Menlo`, monospace.
- Wordmark: all caps with wide tracking.

## Voice

Short and declarative. Technical claims must be literal. The silly phrase can appear in headlines, but documentation should use “browser-native agent runtime” when precision matters.

Good:

> Stuff the agent into the browser.
>
> DOM in. Local model. Browser actions out.

Avoid:

> Revolutionary AI magic that transforms the way you surf the web.

## Asset usage

- `logo-primary.svg`: README headers, landing page, launch posts.
- `logo-mark.svg`: extension icon, favicon, compact placements.
- `social-card.svg`: launch / Open Graph artwork.
